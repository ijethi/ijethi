## Selected projects

### [Resume Autofill Assistant](https://github.com/ijethi/JobApplicationExtention)

A Chrome extension for reducing repetitive job-application form entry.

- Matches form fields to a structured profile using labels, autocomplete attributes, placeholders, and other page signals.
- Provides confidence scores and a review panel so users can inspect the suggested entries.
- Includes local profile storage and rules for excluding sensitive fields.

**Built with:** TypeScript, Vite, Chrome Extension APIs, HTML, CSS.

### [Park Off](https://github.com/ijethi/parking-platform)

A collaborative parking-discovery project focused on Halifax.

- The current public version includes a responsive homepage and a live Mapbox map centred on downtown Halifax.
- The interface is organized around reusable navigation and map components.
- Backend connectivity, real parking records, sign recognition, and community verification are planned features—not completed capabilities in this version.

**Built with:** Next.js, React, TypeScript, Tailwind CSS, Mapbox GL JS.
